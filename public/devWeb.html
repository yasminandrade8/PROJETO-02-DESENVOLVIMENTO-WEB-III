Sobre a Matéria:

A matéria de Desenvolvimento Web III foca no desenvolvimento backend avançado e na criação de APIs RESTful seguras. O estudante aprende a construir serviços no servidor utilizando frameworks modernos, integrar bancos de dados por meio de ORMs, aplicar mecanismos de autenticação com JWT, escrever testes de integração e documentar rotas com Swagger para realizar o deploy da aplicação na nuvem.

Imagem relacionada

Principais Assuntos da matéria:

- APIs REST e RESTful: Criação de rotas, manipulação de requisições/respostas HTTP, status codes e padronização de arquitetura.
- Frameworks Backend Avançados: Construção de aplicações no servidor usando ecossistemas modernos (como Node.js/Express/NestJS, C# ou Java).
- Autenticação e Autorização: Implementação de segurança com JWT (JSON Web Token), OAuth, criptografia de senhas e controle de acesso por funções (RBAC).
- Persistência com ORMs: Mapeamento objeto-relacional para integração com bancos de dados relacionais e não-relacionais (como Prisma, TypeORM ou Sequelize).
- Testes Automatizados: Escrita de testes unitários e de integração para garantir a qualidade e estabilidade das APIs.
- Deploy e Documentação: Publicação de serviços em ambientes de nuvem e documentação interativa de rotas com ferramentas como Swagger/OpenAPI.
