Sobre o Curso

O curso de tecnologia em Desenvolvimento de Software Multiplataforma da FATEC é um tecnólogo gratuito de 3 anos focado em formar profissionais para criar, testar e implantar sistemas para web, mobile, desktop e nuvem. A formação combina programação Full Stack, banco de dados, engenharia de software, UI/UX e metodologias ágeis, preparando o estudante para atuar como desenvolvedor, analista ou engenheiro de software no mercado de tecnologia.
